# Inner Visions Design editable homepage

This website is prepared for Pages CMS. It uses **no build tools**.

## First upload
Upload the **contents** of this folder to the root of your GitHub repository, not the ZIP archive and not the containing folder.
Make sure `.pages.yml` is included; it is a hidden file on some computers.
The files should include `index.html`, `.pages.yml`, `content/home.json`, and the `assets/` folder.

## Connect the editor
1. Go to https://app.pagescms.org and sign in with GitHub.
2. Allow the app to access `Inner-Visions-Design`.
3. Choose the repository and `main` branch.
4. Select Homepage; you can edit the labeled text and images and save.

## Publish later
In the repository, GitHub > Settings > Pages > Build and deployment > Deploy from a branch; select `main` and `/ (root)` then Save. You can use the GitHub Pages preview URL before changing GoDaddy DNS. Note that GitHub Pages may take a few minutes to deploy.

## Important
- Do not add customer data, subscriber names, passwords, API keys or private business records to a public repository.
- The newsletter signup is only a placeholder; no email collector is hooked up yet.
- Contact links use your business email via the visitor's email app.
- Small content changes use the CMS; major layout changes still need code changes.
- Preview your changes after publishing, especially if you change images.
